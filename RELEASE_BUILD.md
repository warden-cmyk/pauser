# Release Build & Manual Test Checklist — Battery Manager

**Status: none of the steps below have been performed.** This session's
environment has no Android SDK, no Gradle installation, no emulator, and
no physical device access - every prior session's `PROJECT_STATE.md`
entry has said the same. Nothing in this document should be read as a
claim that the project builds, runs, or has been tested on a device;
static/code-level checks performed in past sessions (brace/paren
balance, XML/TOML parsing, `R.string.*` cross-referencing) are not a
substitute for any of this and are not restated here as if they were.
This is a checklist for the person doing the actual build/test pass on
their own machine and device.

## Build

1. **Open the project in Android Studio.** Use a recent stable release
   (Android Studio Ladybug/Koala or newer recommended for AGP 8.7.x /
   Kotlin 2.0.x). Open the project's root folder (the one containing
   `settings.gradle.kts`).
2. **Allow Gradle synchronization.** The project's `gradlew`/`gradlew.bat`
   wrapper scripts were hand-transcribed in an earlier session (see
   `PROJECT_STATE.md`'s Session 1 entry) rather than generated by the
   `gradle wrapper` task, and `gradle-wrapper.jar` is not included (it's
   a binary normally downloaded from Gradle's servers, which this
   environment has no network access to fetch). Android Studio
   regenerates the wrapper jar automatically on first sync - let it do
   so, and resolve any AGP-upgrade prompt Android Studio offers before
   continuing.
3. **Connect the Motorola Edge 5G UW (2021).** Enable Developer Options
   and USB debugging on the device first if not already enabled, then
   connect it and confirm Android Studio's device dropdown shows it as
   available.

## Manual test pass

Run the app on the connected device (Run ▶ in Android Studio) and work
through each of the following. This project's own architecture
deliberately does not attempt to verify most of these outcomes in code
(see `GuidedOutcome`/`CleanupOutcome`'s doc comments on why) - they can
only be confirmed by a person watching the device.

4. **Application selection** - confirm the app list loads, checkboxes
   toggle individual apps, and that Battery Manager itself, Android
   Settings, System UI, "Android System," and the device's default
   launcher (if identified) are visibly shown without a checkbox and
   cannot be checked. Confirm Select All / Deselect All behave as
   expected and never select any of those.
5. **Manage Selected** - select a few apps, tap "Manage Selected," and
   confirm each selected app's own Settings ("App info") page opens in
   turn.
6. **Manual Force Stop** - on one app's Settings page, manually tap
   Force Stop yourself (Battery Manager does not do this for you), then
   return to Battery Manager and confirm the guided flow advances.
7. **Skip** - on another app's Settings page (or before it opens),
   tap Skip and confirm the flow advances to the next app without
   requiring a Settings visit.
8. **Skip All** - mid-run, tap "Skip All Remaining" and confirm the run
   ends immediately with every remaining app (including the current one)
   marked skipped.
9. **Cancel** - start a new run and tap Cancel (and separately, on
   another run, press the system Back button) and confirm the run ends,
   the selection is left untouched, and you're returned to the main
   list.
10. **Completion summary** - after a run finishes (via completion, Skip
    All, or Cancel), confirm the summary dialog appears, lists every
    attempted app with an honestly worded outcome ("You confirmed via
    Settings" / "Skipped" / "No longer installed" / "Cancelled" -
    never "stopped" or "force-stopped"), and shows the disclaimer that
    Battery Manager cannot confirm an app was actually force-stopped.
11. **Open Selected** - select one or more apps (including, if you can
    arrange it, one that's been uninstalled since it was last selected)
    and tap "Open Selected." Confirm launchable apps come to the
    foreground and that an unlaunchable one is silently skipped rather
    than crashing Battery Manager.

## Packaging

12. **Build an APK or AAB.** Build ▶ Build App Bundle(s) / APK(s) in
    Android Studio, or `./gradlew assembleDebug` / `./gradlew bundleRelease`
    from a terminal once the wrapper jar exists (see step 2). A release
    build will additionally need a signing configuration, which this
    project does not currently define (see `PROJECT_STATE.md` for what
    has and hasn't been set up).
